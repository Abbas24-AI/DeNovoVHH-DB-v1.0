Overview

DeNovoVHH-DB is an open academic resource that catalogues single-domain antibodies (VHH / nanobodies) across the design → validation continuum. It integrates sequence, structure, target, binding, design-method, and literature evidence into a single provenance-first record for each antibody, with the explicit goal of never conflating what was designed with what was experimentally validated.

Principles

  • No fabrication. Absent evidence is "Not reported", never estimated.
  • Field-level provenance. Every value traces to a source and extraction method.
  • Original + normalized values kept separately.
  • Evidence-graded. E0–E6 flags and status labels on every record.
  • Experimental vs. predicted kept distinct.

Citation

When using DeNovoVHH-DB, please cite the underlying data sources — in particular the ANDD dataset (Zenodo record 18151718) and RCSB PDB / UniProt / Europe PMC as applicable — alongside this resource.

This is a research resource, not a clinical or regulatory database. Nothing here should be read as evidence of therapeutic safety or efficacy.
